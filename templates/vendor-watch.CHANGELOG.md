# vendor-watch — release notes

## 1.0.0 — 2026-09-11

- Baseline release: weekly vendor-page diff watch — re-reads the URL list every Mon 07:00 local and posts only new/gone/changed, with a one-line no-change note on quiet weeks.
- Charter rule: quote the vendor verbatim, never paraphrase a capability into existence; an unreadable page is named, not treated as no news.
- Memory is last week's page text kept for next week's diff; verify holds one dated note per week, cross-checked against bin/gb-sources.py output.
